## Contexto

Sesion de backlog + refinamiento en el repo de Mefisto. Arranco con el backlog en cero (se confirmo el merge previo de los PRs de field notes #746/#749, ya integrados en v0.30.0) y se refino el draft #753, creado desde el consumidor Bitakora.ControlAsistencia.

## Descubrimientos

- **Causa raiz de #753 confirmada y reproducida en la propia sesion**: la allowlist `tools:` de `agents/planner.md` no incluye ningun `mcp__*`, lo que bloquea las herramientas MCP aunque las instrucciones del servidor si se inyectan al contexto (el agente "ve" el servidor pero `No such tool available`).
- **Inventario de MCP oficiales** (via `gh api search`, 2026-08-29): Microsoft Learn si (`MicrosoftDocs/mcp`, endpoint HTTP remoto sin auth `https://learn.microsoft.com/api/mcp`); Azure si pero operativo, no documental (`Azure/azure-mcp`, requiere `az login`); Marten/Wolverine/JasperFx y NuGet/dotnet: ninguno.
- **Formato scoped oficial de tools MCP de plugin**: `mcp__plugin_<plugin>_<server>__<tool>` (code.claude.com/docs/en/plugins-reference, seccion "MCP servers"). Un matcher contra el nombre corto del servidor nunca casa cuando el servidor llega via plugin.
- **Hallazgo colateral confirmado con evidencia local**: el MCP de terraform llega via plugin (`claude-plugins-official/terraform`, stdio docker `hashicorp/terraform-mcp-server:0.4.0`, verificado en `~/.claude/plugins/cache/.../.mcp.json`), asi que el `mcp__terraform__*` de infra-writer no casa y ese agente corre sin terraform MCP en degradacion silenciosa.
- **`jetbrains` esta correcto**: es servidor user-level (`~/.claude.json`), no plugin; los wildcards `mcp__jetbrains__*` de implementer/projection-implementer/reviewer son los nombres reales.
- **Un plugin puede declarar `mcpServers` inline en `plugin.json`**, y `.claude-plugin/*` ya esta registrado en ambos gates de scope -> la via inline evita el PR previo de registro de MEF-ADR-0019 seccion E (que si aplicaria a un `.mcp.json` nuevo en la raiz del plugin).

## Decisiones

- **Alternativa A elegida por el usuario** para #753: Mefisto bundlea el MCP de Microsoft Learn en su propio `plugin.json` (todo consumidor lo obtiene automatico), aceptando explicitamente el costo de contexto en todas las sesiones de pipeline. Se descarto la deteccion opt-in via `/onboard` (B).
- Alcance de #753 acotado al planner publicado; extender a otros agentes queda como decision futura con evidencia propia.
- Fix de #754: declarar **ambas** formas del wildcard en infra-writer (`mcp__terraform__*` + `mcp__plugin_terraform_terraform__*`) -- inocuo cuando una no existe. No se bundlea terraform MCP en Mefisto (stdio docker, dependencia de entorno; seria issue propio).
- Ambos issues comparten protocolo de verificacion post-release (validacion humana en un consumidor; gates documentados en cada issue).
