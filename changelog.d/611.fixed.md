- Se corrige un falso fallo de merge en `pr-sync.sh`: `desbloquear_issues_dependientes()` abortaba con `unbound variable` bajo `/bin/bash` 3.2 (macOS) cuando un issue bloqueado referenciaba el issue recien cerrado con una redaccion no canonica en su seccion `## Dependencias` (p. ej. "Depende del write-side: #N"), dejando el array de dependencias vacio. El crash contaminaba el exit code del merge, que ya habia sido exitoso, y ademas dejaba issues con el label `bloqueado` de mas. Ahora la funcion no aborta con un array vacio, emite un `warn` identificando el issue y la redaccion no parseable, y las dos invocaciones post-merge aislan su exit code (`|| warn`) del resultado del merge.
