- El Stage 2b (smoke-test-writer) de `scripts/tdd-pipeline.sh` ahora se dispara
  cuando un issue agrega o modifica una tool de un servidor MCP
  (`src/{RootNamespace}.Mcp.{Proposito}/.../{X}Tool.cs`): la deteccion de
  `SMOKE_FILES` suma ese patron (ademas de `Function/` y del carve-out
  read-side), `SMOKE_TEST_PROJECT` resuelve al proyecto
  `tests/{RootNamespace}.Mcp.{Proposito}.SmokeTests` del servidor, y el prompt
  del stage identifica el caso MCP para que el agente aplique su doctrina de
  extension de la suite (MEF-ADR-0048) en vez de la de Functions HTTP.
