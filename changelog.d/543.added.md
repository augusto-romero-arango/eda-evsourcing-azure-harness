- Se crea MEF-ADR-0039 (composicion canonica de ensamblados por rol del evento): fija la particion
  incondicional de los tipos de evento de un Bounded Context en
  `<RootNamespace>.PublicEvents`/`<RootNamespace>.PrivateEvents`/`<RootNamespace>.{Dominio}.DomainEvents`
  (criterio "sale del BC"/"cruza el bus interno"/"se persiste en el event store"), el grafo de
  dependencias `PublicEvents <- PrivateEvents <- {Dominio}.DomainEvents <- Function App`, la
  prohibicion mecanicamente verificable de que el worker de proyecciones referencie el `.csproj` de
  cualquier Function App, la reubicacion de `ConfiguracionSerializacion{Dominio}` e
  `IdentidadEventos{Dominio}.TiposPersistidos` a `{Dominio}.DomainEvents`, la regla de que los
  eventos no conocen los comandos, y la muerte de `Contracts` como shared kernel por defecto
  (excepcion local bajo Rule of Three, MEF-ADR-0018). Alcance greenfield-only, con `CA-ADR-0029` de
  Bitakora.ControlAsistencia como receta de referencia de la migracion de consumidores legados
  (no-objetivo explicito de este ADR).
- Se enmiendan, en consecuencia, MEF-ADR-0034 (el worker de proyecciones alcanza los tipos de evento
  persistidos referenciando `{Dominio}.DomainEvents`, cerrando el hueco que MEF-ADR-0036 seccion 6(a)
  dejaba abierto), MEF-ADR-0005 (el envelope de eventos referencia el ensamblado de eventos de bus
  que corresponda, no "el proyecto Contracts"), MEF-ADR-0013 (el csproj de smoke tests referencia
  `PublicEvents`/`PrivateEvents`) y MEF-ADR-0010/0011/0012 (menciones residuales de Contracts
  actualizadas a la particion nueva) para quedar consistentes con MEF-ADR-0039.
