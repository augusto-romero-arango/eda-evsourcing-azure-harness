- El remedio que ofrece el gate de neutralidad de runtime al abortar (pipeline de tooling y `/mefisto-release`) ya no propone siempre registrar una excepcion en la allowlist. La nueva funcion `mefisto_neutrality_remedy` compone, por cada regla presente en la violacion, una linea de remedio propia: para las reglas de texto, reformular la mencion primero (citando MEF-ADR-0050 cuando aplica) y dejar la allowlist como ultimo recurso, solo para contenido correcto y permanente; para el shim y para la verificacion estructural de adaptadores, el remedio estructural que ya les corresponde (restaurar el shim o registrarlo como no migrado; regenerar los adaptadores).
