- Se corrige `/mefisto:upgrade`: `scripts/update-plugin.sh` invocaba `claude plugin update mefisto --scope user` con el nombre del plugin sin calificar, y el CLI lo rechaza (`Plugin "mefisto" not found`) aunque `claude plugin list` lo muestre instalado. Ahora usa `claude plugin update mefisto@<marketplace>` (el `$marketplace_name` que el script ya deriva sin hardcodear), y el mensaje de ERROR sugiere verificar que el plugin este instalado a scope `user`.
