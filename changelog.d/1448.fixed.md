- Los adaptadores de runtime Claude Code y OpenCode (`src/runtime/lib/runtime-claude.sh`, `src/runtime/lib/runtime-opencode.sh`) migran al canal de stdin abierto por #1447: ninguno de los dos vuelve a poner el prompt en el argv del CLI. Claude Code fija `MEFISTO_RUNTIME_STDIN_FILE` directo a `--prompt-file` y recibe el system prompt como `--append-system-prompt-file <ruta>` (nunca su contenido en argv); OpenCode materializa `"$MEFISTO_RUNTIME_WORK_DIR/opencode-message.md"` (system + prompt) y lo declara como stdin, porque `opencode run` concatena mensaje posicional y stdin cuando llegan los dos. Antes, cualquier prompt mayor que `ARG_MAX` (1.048.576 bytes en macOS) hacia que el kernel rechazara el `exec` antes de que el CLI arrancara -- incidente de #1407 (prompt del reviewer de 3.237.916 bytes, `duration_ms: 0`, `session_id: null`). Verificado con paridad entre ambos runtimes ante un prompt >= `getconf ARG_MAX` + 65536 bytes.
